# 关于

这是本站的「关于」页面。它是 `type: page` 的普通页面，与文章不同：页面不参与文章列表，也不带
WIP 属性。

<!--p:01J8Z5Q0K3W7M9V2B4N6P8R3BE-->

页面正文同样保存在 Markdown 里，frontmatter 保存必要元数据。页面创建器最终也把区块结构表达为
Markdown / directive / frontmatter，而不是建立第二套不可重建的正文数据源。
